# To-Do List App

A simple and clean To-Do List application built with **HTML**, **CSS**, and **JavaScript**.

This application allows users to add tasks, mark them as completed, and delete tasks. It also supports pressing "Enter" to add tasks, making the experience smooth and interactive.

## Features
- **Add Tasks:** Add new tasks by typing in the input field and clicking the "Add" button.
- **Mark as Completed:** Click on any task to toggle its completion status (strikethrough).
- **Delete Tasks:** Click the "Delete" button to remove a task from the list.
- **Keyboard Support:** Press "Enter" to add a task, providing a smoother user experience.
